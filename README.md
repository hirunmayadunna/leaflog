# leaflog

LeafLog is a **reading log web app** that helps you track the books you want to read, are currently reading, and have finished.  
Built with **HTML, CSS, and JavaScript**, it is lightweight, fast, and works directly in your browser with persistence using `localStorage`.

## ✨ Features

- 📖 Add, edit, and delete books  
- 🔍 Search by title or author  
- 🏷️ Filter by status (**To-Read, Reading, Done**)  
- ⏳ Sort by title, author, status, or recently added  
- 💾 Persistent storage using localStorage  
- 🎨 Clean and minimal interface
